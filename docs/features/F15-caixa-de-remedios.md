# Feature: Caixa de remédios inteligente e adesão ao tratamento

- **Requisito atendido (RF/RNF):** registrar se o paciente tomou cada dose (pela caixa ou pelo botão "Tomei"), mostrar a adesão no Perfil e a adesão agregada no BI; alertar temperatura/umidade de armazenamento.
- **Disciplina relacionada:** Sistemas Distribuídos e IoT; Segurança (pareamento, token com hash, revogação, LGPD); Padrões de Projeto (State no firmware); BI; Estatística (taxa de adesão); Programação Multi Plataforma (C++, TypeScript, SQL).
- **Padrão ou tecnologia usada e por quê:** ESP32 + máquina de estados (State); funções `security definer` no PostgreSQL para a caixa não acessar tabelas; Repository (Mock e Supabase) no app; Observer para o aviso "Você tomou?". Ver ADR-017 e ADR-018 (modo demonstração pelo app, status do sensor e toques).
- **Arquivos principais:** `db/10_caixa.sql`, `db/11_caixa_demo.sql`, `db/ci/tests_caixa.sql`, `firmware/caixa-infomed/*`, `firmware/teste-leds-sensor/teste-leds-sensor.ino`, `scripts/caixa-config.mjs`, `scripts/simulador-caixa.mjs`, `src/app/domain/adherence.ts`, `src/app/domain/device.ts`, `src/app/features/adherence/*`, `src/app/repositories/*Device*`, `src/app/repositories/*Adherence*`, `src/app/components/screens/MedicineBox.tsx`, `Profile.tsx`, `RemindersList.tsx`, `Dashboard.tsx`, `features/reminders/ReminderAlerts.tsx`.
- **Como testar:** `npm test` (arquivo `features/adherence/adherence.test.tsx`: janela da dose, períodos, selos de hoje, adesão, pareamento na tela, botão do modo demo, sensor sem sinal, temperatura baixa, toques, botão "Tomei", aviso "Você tomou?"); banco: `psql -v ON_ERROR_STOP=1 -f db/ci/tests_caixa.sql` depois dos scripts 01-11; hardware: `docs/hardware/caixa-de-remedios.md`.
- **Evidência (print ou diagrama):** a fazer: foto da caixa montada, print do "Caixa pareada ✅", do selo ✅ nos Lembretes e do bloco de adesão no BI (salvar em `docs/evidence`).
- **Observações / dificuldades encontradas:** o firmware não foi compilado no ambiente de desenvolvimento (sem toolchain do ESP32 instalada); compilar na Arduino IDE é o primeiro passo da bancada. Rede da faculdade com página de login não funciona com o ESP32: usar o roteador do celular.
